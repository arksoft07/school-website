SCHOOL WEBSITE - EDITING GUIDE

Files:
- index.html   = main school website
- staff.html   = teacher + support staff page
- style.css    = website design
- script.js    = menu/toast functions

STAFF PAGE:
There are 17 teacher cards + 1 librarian + 1 peon + 1 night guard.
For each card you can replace:
1. Placeholder (T01 etc.) with a photo using:
   <img src="images/teacher01.jpg" alt="Teacher Name">
2. Teacher 01 with the person's name
3. Subject Teacher with subject/designation
4. +91-XXXXXXXXXX with the mobile number

Create an "images" folder and put staff photos inside it.

IMPORTANT:
Publishing personal mobile numbers makes them public. Get staff permission before adding numbers.

FREE HOSTING:
This is a static website and can be hosted on GitHub Pages, Cloudflare Pages, or Netlify.
